# GlassDigestor 0.6.0-pre-alpha.21

Version code **27**. Previous published APKs remain available as fallbacks.

Owned image, video and archive previews now use a bounded MPV still when the
platform decoder declines an eligible file. A manual **MPV still image** mode
also opens an exact selected interval. Platform metadata and MPV observations
stay separately labelled; the frame has an unknown timestamp and does not
establish playback or complete-file integrity.

The isolated worker receives a separately staged source and fresh raster FD.
Native display/sample-aspect bounds apply before screenshot allocation;
returned nodes, dimensions, stride, alpha and pixels are checked. The parent
verifies source identities, raster length/SHA-256 and explicit RGBA-to-ARGB
conversion, then removes temporary inputs/outputs before publication.
Automatic thumbnails use 256 pixels and 32 MiB acquisition; explicit stills
allow a 1536-pixel edge and 256 MiB input, with separate native read/time/raster
limits. Decoder-internal allocations are outside these adapter limits.

Only documented unsupported/malformed MediaPlayer errors admit automatic
fallback. IO, timeout, service and unknown failures retain their original
status. Cancellation, policy, source changes and stale viewer generations
cannot start or publish a replacement preview.

Every worker engine now checks report descriptors before dispatch and before
writing, including error replies. A report must be writable and distinct from
all data descriptors by kernel device/inode identity. Unsafe or unverifiable
channels close without changing the active request or writing into inspected
bytes. The new actual-runtime contract probes valid, unsupported and empty
aliased sources, then requires native hashing to recover on the same connection.

Expanded explanations use information, details and comparison language.
Original inspected text, upstream output, existing schema/type identities and
compatible installation namespace remain intact.

Authored FFV1/Matroska, TIFF/PPM, exact pixels, square/anamorphic/extreme sample
aspect and malformed/limit cases exercise real host MPV. Sixty-one independent
model/raster checks and targeted host Android lifecycle/ownership/error cases
pass; ARM64 JNI compilation and corresponding-source bundle checks pass.
The current full CI and platform acceptance results are recorded in
[Status](../STATUS.md) and the [feature checklist](../FEATURE-PARITY.md).

Actual ARM64 MPV/isolated decoder execution, arbitrary codecs, playback, full
handset UI/SAF, fragmented recovery, remaining NIST corpus cases and full desktop
parity remain incomplete. The x86 runtime laboratory packages hash/archive/
PhotoRec engines and exercises shared protocols; it contains no native MPV.
The application remains offline, GPL-3.0-only and debug signed. Stable signing,
a source-built replacement for the packaged official MPV runtime and F-Droid
acceptance remain future work.
