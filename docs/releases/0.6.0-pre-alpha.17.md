# GlassDigestor 0.6.0-pre-alpha.17

Published checkpoint, version code **23**, source `7c80322`.
[Download pre-alpha.17](https://github.com/sperglord8008s/GlassDigestor/releases/tag/v0.6.0-pre-alpha.17).
Pre-alpha.16 and earlier releases remain immutable fallbacks.

String investigation now puts **why this category** beside the actual matched
text. Category-specific summaries, highlighted tokens, mechanism explanations,
next checks, exact byte/UTF-16 spans and the original raw evidence remain
together. Eight-occurrence detail pages retain every returned match and its
original index. Definitions collapse individually or together; primary evidence
precedes source bookkeeping on a small screen. Classifier 1.1.0 retains all
43 rules and 16 overlapping groups; category rationale participates in its
catalog identity. A text match still does not establish execution or a confirmed
vulnerability.

Whole strings and exact matches gain **Copy**, **Search…** and **Translate…**.
Choose DuckDuckGo, Google, Bing or Brave for search, or Google Translate, Bing
Translator or DeepL for English translation. The app explains the external
handoff before engine selection and opens Android's browser chooser. Only the
engine ID is saved. There is no automatic submission, query history or added
INTERNET permission. Local copy preserves exact captured UTF-16; modern Android
clips are marked sensitive. Oversized transfers and invalid browser text are
refused explicitly without silent truncation. Selectable evidence text also
offers search/translation while preserving Android Copy.

Explore now groups identity, APKs, directories, components and permissions, with
bold names, labelled values and thin separators. Counts exclude section headers;
filters remove empty groups. Existing acquisition, split, package-knowledge,
declared-service, filesystem and Binder routes are preserved. Shared readable
section/fact/code/prose roles apply throughout the core viewers and galleries.
