# GlassDigestor 0.6.0-pre-alpha.19

Development checkpoint, version code **25**. Publication is pending. Pre-alpha.18
and all earlier APKs remain immutable fallbacks.

Binwalk now has a visible time-limit setting: 120 seconds by default, custom
whole seconds 1–1800, with 30 additional seconds for worker startup/reporting.
Both native and worker limits are captured per request, retained in information
and enforced before publishing a result. Cancellation and descriptor ownership
remain intact; legacy captures stay readable.

Strings gains its minimum setting beside the strings, live search/count and
a direct complete-list route using the same query. Categories and Why this
classification? replace generic navigation language. Captured scan/minimum
state remains distinct from next-analysis settings.

Lists have functional draggable thumbs; details have a hit-tested scrolling
thumb. Definition controls are compact. The Gallerize grids support pinch/±
zoom, two-finger pan and contiguous multi-block selection with exact range
Hex/preview/analysis/export/archive actions and retained state.

Options now opens About and a private bounded debug log, with actual build
identity, safe structural diagnostics, copy/export and clear. UI language uses
Information, Details and Source. No app identity/signing/INTERNET change.

Project navigation is consolidated around STATUS, PROJECT-MAP and continuation;
19 fully merged remote branches were removed without discarding commits and
unfinished MPV work is preserved in a named remote savepoint. Independent NIST
file-export tooling pins all six L0_Video payload hashes; current host baseline
is 5/6 exact files, with additional exports retained and MPEG work queued.

Local focused checks pass: 62 Android host cases, eight Rust checks, Binwalk
JNI descriptor/64 MiB/configured-limit fixtures and ARM64 bridge compilation.
Full-suite, production assembly/lint/static, clean CI and actual Android
regressions remain pending. [Control/verification contract](../workbench-usability.md).


A twelfth test-only Android contract now compiles directly. It checks real
captured preferences/Bundle/Parcel values and private diagnostics storage,
alias/refusal/privacy/retention behavior. All eleven earlier native/media/
clipboard contracts remain intact. Actual API 26/35 execution is pending; this
new contract explicitly does not execute Binwalk JNI, full UI or SAF.
