# GlassDigestor 0.6.0-pre-alpha.18

Development checkpoint, version code **24**. Publication and actual Android
verification of this source are pending. Pre-alpha.17 and all earlier APKs
remain immutable fallbacks.

This fixes the reported **Unexpected non-regular archive cache entry** failure.
A trusted Android cache ancestor can have an operating-system path alias;
comparing its lexical spelling with the canonical leaf path incorrectly
rejected regular files. Archive sessions, origin records and staged decoded
inputs now anchor their trusted roots before generating private leaves.
Generated leaf symlinks and escapes are still refused, with outside bytes
preserved. Session cache validation precedes native reanalysis.

Archive/compression identification and **Browse contents / decompress / save
files** now precede generic desktop parser facts on the main scan. An Archive
detection also offers **Browse / extract**, bound to the original captured
input. The whole-input action does not invent an embedded archive extent.
A completely inventoried single regular member has direct **Open decoded file**
and **Save decoded file…** actions in list mode. Member details put actions
before metadata. Gallery retains direct card actions and its useful viewport.
Decoded previews offer **Gallerize** using an independently owned exact copy,
so closing the preview does not invalidate the discovery input.
